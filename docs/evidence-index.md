# Bảng minh chứng

Quy tắc: chưa thử thì ghi **Chưa kiểm tra**. Ảnh chụp phải cắt bỏ tab lạ, email/tài khoản, thông báo. Link minh chứng phải mở được bằng cửa sổ ẩn danh.

| Mã | Tuyên bố | Phép thử | Kết quả thật | Minh chứng |
|----|----------|----------|--------------|------------|
| E1 | Nút "Khám phá" cuộn tới mục thông tin | Bấm nút trên URL Pages | Chưa kiểm tra | |
| E2 | Ảnh đại diện và ảnh nền hiển thị | Mở URL Pages, xem tab Network (không 404) | Chưa kiểm tra | |
| E3 | `css/style.css` được tải trên Pages | Tab Network: trạng thái 200 | Chưa kiểm tra | |
| E4 | Nút "Gửi email" mở đúng địa chỉ | Bấm nút, đọc địa chỉ nhận | Chưa kiểm tra | |
| E5 | Hiển thị đúng ở 1280 / 768 / 390 px | DevTools responsive, chụp 3 kích thước | Chưa kiểm tra | |
| E6 | URL Pages khớp phiên bản nộp | Đối chiếu commit triển khai với tag v8 | Chưa kiểm tra | |
| E7 | Link minh chứng mở được | Mở bằng cửa sổ ẩn danh | Chưa kiểm tra | |
